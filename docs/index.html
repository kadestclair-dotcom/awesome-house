Every listing you post on a hunch, every material you buy at the wrong time, every gear piece you replace without checking costs gold. This app puts the numbers in front of you.

No black box

See how the upgrade score works.

Some tools give you a number and ask you to trust it. This one shows its math. The efficiency score multiplies how many stat points an item is worth by how well those stats suit your class.

Items with no stats published by Blizzard get a fit of 50%, shown with a ~ so you know it is an estimate. You can also switch to comparing stats only, or item level only.

Efficiency = Power × Fit

Power estimates stat points from item level, quality and slot, using the Classic item-budget formula. Fit is the share of the item's main stats your class values. Weapon DPS and armor are added on top.

QualityBase budget
Uncommon(ilvl − 8) / 2
Rare(ilvl − 0.75) / 1.8
Epic(ilvl − 26) / 1.2

Then multiplied by a slot modifier: 1.0, 0.75, 0.5625, 0.4219 or 0.3164.

Private by design

Your key. Your data. Your PC.

There is no account to make, no shared login and no server collecting your lists. You create your own free Blizzard API key, and the app keeps everything beside itself on your computer.

Stays on your computer

  • Your Blizzard API ID and secret
  • Watchlist and alerts
  • Price history database
  • Characters you looked up
  • Guide progress and fishing sessions
  • Tracked monsters, kill counts and notes

Goes over the internet

  • Login and data requests to Blizzard's servers, using your own key
  • GitHub, once, to download the free QuestieDB monster data when you first open the Monster Compendium (and when you click Update data)
  • Wowhead or Warcraft Wiki, only when you click a link, and only in your browser

The app never asks for your Battle.net password. Every other request stays on your machine.

Get started

Ready in about five minutes.

  1. Download it and give it its own folder

    Get the latest zip from the official Releases page, github.com/kadestclair-dotcom/awesome-house/releases, and unzip it into a folder such as Desktop\Awesome House. The app saves its files beside itself, so a dedicated folder keeps them together.

  2. Open it

    Windows may say "Windows protected your PC." Click More info, then Run anyway. The first launch takes a few seconds while it unpacks.

  3. Make your free Blizzard API key

    A setup window opens with a button that takes you to develop.battle.net. Create a client there, then paste the Client ID and Secret into the window. You only do this once. The next section walks through every field on Blizzard's form.

  4. Search, add, and let it watch

    Search for an item, add it to your Watchlist, and set an alert. Leave the app open and it checks again every hour, building your price history as it goes.

Key setup

Blizzard's form, field by field.

Your key is a free "API client" on Blizzard's developer site. The form is written for website developers, so it asks about redirect and service URLs. This app doesn't use either of them. It only needs the Client ID and Client Secret you get at the end.

  1. Click the button in the app's setup window, or go to develop.battle.net/access/clients, and sign in with your normal Battle.net account.
  2. Choose Create Client and fill in the form as shown below.
  3. Save, then open your new client to see its Client ID and Client Secret.
  4. Copy both into the app's setup window and click save. You're done.

Straight talk

What to know before you run it.

Every tool has limits, and this one is still in beta. Here are its limits, plainly, with what to do about each.

TopicWhat it meansWhat to do
Beta software
Expect bugs		 Awesome House is at Beta 0.14. Features are still being added and some things will break or change between versions. Use Support > Report a bug when something looks wrong. Screenshots help.
Windows warning
Expect it		 The app is not code-signed, so Windows SmartScreen shows "Windows protected your PC." Some antivirus programs also wrongly flag apps packaged with PyInstaller. Click More info, then Run anyway. Only download from the official GitHub Releases page, where every release is built by GitHub from the public code. If your antivirus flags it, check the zip against SHA256SUMS.txt on the release.
Your API secret is stored as plain text
Protect it		 Your Client Secret is saved in wow_price_config.json next to the app. Anyone who gets that file could use your key. Do not zip up and share the app folder after you have set it up. If it leaks, delete the client at develop.battle.net and make a new one.
Unofficial data source
May change		 Blizzard's WoW: Forever API was undocumented as of November 2026, so endpoints can change and break parts of the app. Keep an eye out for updates if a tab stops loading.
Some items have no data
Limit		 Blizzard's item lookup is missing many Classic-era items in Forever. One developer found 652 of 1,515 auction item IDs missing. Expect gaps in names, stats and upgrade results. The "Why these results?" panel shows when data is the reason.
Monster data is community-made
Limit		 The Monster Compendium uses QuestieDB, the Questie addon's community database. Its Forever data is still filling in, so some new monsters, drops and quests are missing. Drop chances are only known for quest items. Click Update data now and then to get the latest release. Use the Wowhead link to double-check a drop before you farm for hours.
History starts when you do
Limit		 Price history is recorded only while the app is open, one point per hourly snapshot. Trends need time to fill in. Leave it running in the background while you play, especially for items you care about.
Estimates, not promises
Limit		 The auction house cut is assumed to be 5%, the Classic rate, and is not confirmed for Forever. Upgrade scores use rough leveling weights and are not a full simulation. Treat results as a strong starting point. Check the tooltip on anything big before you spend or sell.
Not real-time
Limit		 Blizzard refreshes auction data about once an hour. Prices you see can be up to an hour old. Re-check in game before a large purchase.
New characters
Limit		 In Forever, characters only show up in lookups from level 10, after you log out. If a lookup fails, log out and try again in a few minutes.

Questions

Quick answers.

Does it touch my game account?

No. The app does not interact with the game client and never asks for your Battle.net password. It reads data through Blizzard's public developer API using a key you create yourself.

Does the Blizzard API key cost anything?

No. Blizzard API keys are free to create at develop.battle.net, and the app needs nothing else running in the background.

Does it work for retail WoW?

Yes. It is built for WoW: Forever and supports retail as well. For retail, character lookups use the character name and realm. The Monster Compendium covers Forever only.

Where does the monster data come from?

From QuestieDB, the free community database behind the Questie addon. It isn't packed into the app: the first time you open the Monster Compendium, the app asks before downloading it from GitHub (about 14 MB) and keeps it on your computer.

Can I back up or move my data?

Everything lives in files beside the app, so copying the folder moves your watchlist, history and tracked monsters. Keep in mind that it also copies your API secret, so only move it between your own computers. You can export price history and fishing sessions to CSV from the app.

Can I share it with friends?

Please send them the official download page, github.com/kadestclair-dotcom/awesome-house/releases, instead of passing your copy on. The license asks that copies only come from there, and once your copy is set up, its folder holds your private API secret.

What if my antivirus blocks it?

This happens with many apps built the same way. If you trust where you got the file, add the app's folder as an exception, or ask whoever shared it for the checksum so you can verify the file is unchanged.
