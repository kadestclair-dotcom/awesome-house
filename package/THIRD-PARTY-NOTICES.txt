Third-party software in Awesome House
=====================================

AwesomeHouse.exe is built with PyInstaller and contains other people's
software. Their licenses are not the Awesome House license; they stay under
their own terms, listed here. Awesome House's own terms are in LICENSE.txt.

Python and the libraries built into it
  The exe contains the Python interpreter and parts of its standard library,
  Copyright (c) 2001 Python Software Foundation; All Rights Reserved.
  Licensed under the PSF License Agreement. Python for Windows also includes
  OpenSSL (Apache License 2.0; Copyright The OpenSSL Project Authors), libffi,
  bzip2, zstd, Tcl/Tk and the Microsoft C runtime. The full license texts of
  Python and of each of these are in PYTHON-LICENSE.txt, next to this file,
  copied unchanged from the Python installation the exe was built with.

PyInstaller
  The exe is packed with PyInstaller (GPL 2.0 with an exception that allows
  apps it builds to use any license). No notice is required; it is credited
  here anyway. https://pyinstaller.org

QuestieDB (downloaded by the app, not included in it)
  The Monster Compendium, Dungeons and Progress tabs read QuestieDB, the
  Questie addon's community database (github.com/Questie/QuestieDB), by the
  Questie team and contributors. The app downloads its official release from
  GitHub onto your computer when you choose to. It is used with the Questie
  team's permission (given November 12, 2026) and stays under its own license:
  https://github.com/Questie/QuestieDB/blob/master/LICENSE.md
